This repository contains the two datasets generated by my web scraping programs for the FAST School of Computing Data Scraping Assignment.

Datasets
1. Static Product Catalog

File: 23L_0614_versionC_static_products.csv

This dataset contains product information collected from the PokéMart product catalog.

The scraper navigated through the complete catalog using the website's pagination and visited each product's detail page to collect the required fields.

Dataset statistics:

Listing pages processed: 48
Unique products collected: 755
Successfully extracted: 755
Failed requests: 0
Duplicate products: 0

Columns:

Product name
Price
SKU
Stock level / availability text
Tags/categories
Short description
Product detail-page URL
Listing page number on which the product first appeared
2. Dynamic Testimonials

File: 23L_0614_versionC_dynamic_testimonials.csv

This dataset contains customer testimonials collected from the dynamically loaded testimonials page.

A normal requests request initially returned only 10 testimonials. Selenium was then used to progressively scroll the page and collect the additional testimonials loaded by JavaScript.

Dataset statistics:

Initial static testimonials: 10
Scroll batches processed: 7
Batches containing new data: 5
Final unique testimonials: 60
Successfully extracted: 60
Failed/empty records: 0
Duplicate testimonials: 0
Rating values: 1–5

Columns:

Testimonial text
Rating
Scroll batch

Scroll batch = 0 represents testimonials present before any scrolling.

Validation

Both datasets were validated after scraping.

For the static catalog, the number of unique products collected (755) matched the number reported by the website (755).

For the dynamic testimonials, the initial static HTML contained only 10 testimonials, while Selenium collected 60 unique testimonials, confirming that additional records were dynamically loaded during scrolling.

Duplicate checks passed for both datasets, and no failed records remained in the final datasets.
